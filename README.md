# 🌙 Dreem Walker - Backend Server

A robust backend RESTful API built with **Laravel**, integrated with **Filament Admin** for powerful backend management and **Laravel Sanctum** for secure token-based authentication.

## 🛠️ Tech Stack & Features

- **Framework:** Laravel (PHP)
- **Admin Panel:** Filament Admin (for managing resources, users, and content)
- **Authentication:** Laravel Sanctum (Token-based SPA/API authentication)
- **Database:** PostgreSQL
